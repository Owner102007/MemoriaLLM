# Как участвовать

Спасибо за интерес к проекту. Ниже — то, что стоит знать до первого PR.

## С чего начать

1. Прочитайте [CLAUDE.md](CLAUDE.md) — там зафиксированы архитектурные
   решения, которые не пересматриваются без явного согласия владельца
   (Flutter, pdfrx, drift, appDataFolder вместо своего сервера, OAuth без
   Google Play Services).
2. Загляните в [PROGRESS.md](PROGRESS.md) — работа идёт сессиями, каждая
   закрывает одну задачу; там же список того, что уже сделано и что дальше.
3. Возьмите issue с меткой `good first issue` или заведите свою.

## Правила, которые важнее стиля

**Каждый баг сначала воспроизводится тестом, потом чинится.** Регрессионный
тест остаётся в репозитории. Это не бюрократия: геометрия читательской рамки
и слияние CRDT — те места, где ошибка тихо портит данные пользователя.

**Комфорт чтения — функция первого класса, а не полировка.** Любое изменение
в читалке проверяется вопросом: страница по-прежнему занимает весь экран,
вёрстка не поехала, глазам не хуже?

**Изящная деградация.** Нет сети — локальная модель. Нет модели — понятное
предложение скачать. PDF без текстового слоя — честное сообщение при импорте.
Конфликт синхронизации — слияние, а не потеря данных.

**Секреты не хардкодятся никогда.** Репозиторий публичный: утёкший ключ виден
всему миру за минуты. Только GitHub Secrets, секреты Worker'а и локальный
`.env` из `.gitignore`. Если секрет попал в коммит — сообщите немедленно,
ключ будет отозван.

## Технические требования к PR

- `flutter analyze` без замечаний (анализ строгий, `--fatal-infos`).
- `flutter test` зелёные.
- `dart format .` применён.
- Ничего не мержится при красном CI. Зелёный CI на обеих платформах —
  критерий готовности.
- Комментарии и сообщения коммитов — по-русски, код и идентификаторы —
  по-английски.

## Что покрывается тестами обязательно

Геометрия читательской рамки (обрезка полей, деление на части, определение
колонок, сохранение позиции), логика слияния CRDT, извлечение текста из PDF
на корпусе `test/fixtures`, роутер LLM (таймауты, 429, обрыв стрима,
фолбэки), контраст тем. Чужой код — рендеринг PDFium, качество самих
моделей — не тестируем.
