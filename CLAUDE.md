## Раскладка
```
lib/domain/          модели и правила без зависимостей; map/ — карта точной арифметикой
lib/application/     сценарии: чтение, полка, карта, данные
lib/infrastructure/  pdfrx, drift, файлы, обложки, платформа
lib/ui/              экраны; galaxy/ — «Галактика»
lib/sno/, eye/       СНО2026 — уходит после В1, новое не пишется
test/                тесты; map/ — «Галактика», fixtures/ — корпус PDF
docs/history/        прежние CLAUDE.md, PROGRESS.md, BACKLOG.md
```
Зависимость внутрь: `ui → application → domain`; `infrastructure` реализует интерфейсы домена.

## Среда и команды
Flutter — `.github/actions/flutter` (3.47.4), зависимости — по замку.
```bash
flutter pub get --enforce-lockfile
dart format --output=none --set-exit-if-changed .   # 1. формат
flutter analyze                                      # 2. анализ (строгий)
flutter test                                         # 3. тесты
dart run build_runner build --delete-conflicting-outputs   # drift после правки схемы
flutter test test/sno --dart-define=SNO_BRANCH=I     # ветви СНО2026 (и II)
flutter build apk --release --flavor full; flutter build windows --release
```
Эталоны (`--update-goldens`, `tool/make_*_goldens.py`) — только шагом. Без владельца: `msix:create --store`, публикация релиза. CI: формат → анализ → тесты → сборки; в `main` — только при зелёном.

## Правила кода
1. ID — в имени теста (`test('F-READ-11: …')`), в `// ID` у главного места и в коммите (`S52 F-…: …`).
2. Дефект: сначала красный тест, потом починка. Тест остаётся.
3. Только состав шага; найденное по пути — `BUG-…`/`F-… 💡`.
4. Секретов в коде нет: GitHub Secrets, секреты Worker'а, `.env` в `.gitignore`.
5. Изящная деградация: нет сети, модели, разрешения, слоя — понятное сообщение.
6. Новое — после разведки (`RS-nn`); заимствованное — с шапкой «источник, версия, лицензия» и строкой в `Лицензии.md`.
7. Комфорт чтения — первого класса: страница во весь экран, вёрстка цела.
8. Карта побитово одинакова везде: только `domain/map/exact_math.dart`, сверка с `tool/make_map_goldens.py`.
