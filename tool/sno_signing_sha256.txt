# Отпечаток ключа подписи сборок ветвей СНО2026 (SNO-F-REC-13).
#
# SHA-256 сертификата, которым подписаны `memoria-sno2026-I.apk` и
# `memoria-sno2026-II.apk`. Это не секрет: отпечаток виден в любом
# подписанном APK. Сам ключ лежит у владельца и приходит сборке
# секретами репозитория (`ci.yml`, шаг «Собрать APK»).
#
# CI сверяет подпись собранных APK ветвей с этой строкой (шаг «Чем
# подписан APK»): сборка, подписанная другим ключом, не встанет поверх
# прежней и унесёт записи с телефонов — такой прогон красный.
#
# Пока строки с отпечатком нет, сверять не с чем: прогон печатает
# отпечаток замечанием, и его надо вписать сюда — 64 шестнадцатеричных
# знака одной строкой, без двоеточий.
