# Версия PDFium для корпус-тестов — одно место на весь проект (S6.2.1).
#
# Зачем файл. В сборки библиотеку приносит пакет `pdfium_dart` хуком
# `hook/build.dart`, а в среде `flutter test` этот путь ненадёжен, и
# библиотеку кладёт CI. Значит, одна и та же версия движка записана в
# двух местах — у нас и в чужом пакете, — и разойтись они могут молча.
# Отсюда правило: версия здесь **обязана совпадать** с `_pdfiumRelease`
# в `pdfium_dart/hook/build.dart`; расхождение ловит тест
# `test/tool/pdfium_version_test.dart`.
#
# Как обновлять (отдельной сессией, по сигналу канарейки):
#   1. посмотреть `_pdfiumRelease` в hook'е той версии `pdfium_dart`,
#      которая стоит в `pubspec.lock`;
#   2. прописать его в `release` (с косой чертой, не с `%2F`);
#   3. скачать и пересчитать сумму:
#      curl -sSL -o p.tgz "https://github.com/bblanchon/pdfium-binaries\
#      /releases/download/chromium%2F<номер>/pdfium-linux-x64.tgz"
#      sha256sum p.tgz
#
# Сверка суммы, а не наличия файла: недокачанный или подменённый архив
# проходил `test -f` и валился уже внутри тестов, где причина не видна.
