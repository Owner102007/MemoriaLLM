# Эталон одинаковости записи и теста в ветвях СНО2026 (SNO-F-REC-17).
#
# Один и тот же сценарий действий участника проигрывается прогоном
# ветви I и прогоном ветви II (test/sno/branch_parity_test.dart); что
# из него вышло — виды событий журнала с набором полей каждого, файлы
# записи, поля сведений записи и показателей теста — сверяется с этим
# файлом в обоих прогонах. Расхождение валит прогон: значит, запись
# или тест в ветвях стали разными либо изменились в обеих.
#
# Строка: «что | поля строки | поля data». У кадров раскладки
# (layout.jsonl, SNO-F-REC-03) вместо полей data — виды зон, собранные
# со всех кадров сценария. Поля — по алфавиту; у вида
# события они собраны со всех его строк в сценарии. События, которые
# пишет только ветвь II (карта, подготовка книг — kSecondBranchEvents),
# сюда не входят.
#
# Правится осознанно, вместе с кодом: тест при расхождении печатает
# то, что вышло, строками «ЭТАЛОН».
